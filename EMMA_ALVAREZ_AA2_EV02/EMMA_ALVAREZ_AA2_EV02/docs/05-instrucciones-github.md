# Versionamiento con Git y GitHub

## 1. Crear repositorio
Crear un repositorio público o privado llamado:

`sistema-inventario-ga7-aa2-ev02`

## 2. Comandos
Desde la carpeta raíz del proyecto:

```bash
git init
git add .
git commit -m "GA7-220501096-AA2-EV02 - modulo inventario"
git branch -M main
git remote add origin https://github.com/TU-USUARIO/sistema-inventario-ga7-aa2-ev02.git
git push -u origin main
```

## 3. Actualizar repositorio
Cada cambio puede registrarse con:

```bash
git add .
git commit -m "Actualizacion modulo inventario"
git push
```

Después de crear el repositorio, copiar su enlace en `repositorio.txt`.
