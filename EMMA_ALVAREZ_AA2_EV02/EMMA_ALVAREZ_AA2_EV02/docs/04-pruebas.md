# Pruebas realizadas

## Pruebas unitarias
Se creó `InventarioServiceTest` con JUnit 5 para comprobar:
1. Búsqueda de un producto existente.
2. Registro de un producto.
3. Eliminación de un producto.

## Pruebas funcionales manuales
- Abrir la página principal.
- Ingresar al inventario.
- Registrar un producto.
- Consultar la lista.
- Buscar por nombre.
- Editar un producto.
- Eliminar un producto.
- Verificar mensajes de confirmación.

## Resultado esperado
Las operaciones deben ejecutarse sin errores y los datos mostrados en JSP deben corresponder con las operaciones realizadas desde los formularios.
