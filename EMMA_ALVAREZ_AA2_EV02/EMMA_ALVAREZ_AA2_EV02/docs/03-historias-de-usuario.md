# Historias de usuario

### HU-01 Registrar producto
Como administrador de una tienda, quiero registrar productos con nombre, categoría, cantidad y precio para mantener actualizado el inventario.

### HU-02 Consultar productos
Como usuario, quiero visualizar los productos registrados para conocer las existencias disponibles.

### HU-03 Buscar productos
Como usuario, quiero buscar un producto por nombre para encontrarlo rápidamente.

### HU-04 Actualizar producto
Como administrador, quiero editar la información de un producto para corregir o actualizar sus datos.

### HU-05 Eliminar producto
Como administrador, quiero eliminar productos para retirar del inventario aquellos que ya no se comercializan.
