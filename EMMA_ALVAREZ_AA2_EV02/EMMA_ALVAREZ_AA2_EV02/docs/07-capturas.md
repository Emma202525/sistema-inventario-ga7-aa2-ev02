# Capturas para anexar

Para fortalecer la evidencia, agregar después de ejecutar el proyecto capturas de:
1. Página de inicio.
2. Listado del inventario.
3. Formulario de registro.
4. Producto registrado.
5. Edición de producto.
6. Resultado de búsqueda.
7. Consola mostrando pruebas exitosas.
8. Repositorio de GitHub.

Estas capturas pueden incorporarse a un documento PDF si el instructor las solicita.
