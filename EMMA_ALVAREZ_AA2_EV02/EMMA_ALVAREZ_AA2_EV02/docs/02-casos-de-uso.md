# Casos de uso del módulo

## CU-01 Registrar producto
**Actor:** Administrador/usuario de la tienda.

**Flujo:** El usuario selecciona Nuevo producto, diligencia nombre, categoría, cantidad y precio y presiona Guardar.

## CU-02 Consultar inventario
**Actor:** Administrador/usuario de la tienda.

**Flujo:** El usuario ingresa al inventario y el sistema muestra los productos registrados.

## CU-03 Buscar producto
**Actor:** Administrador/usuario de la tienda.

**Flujo:** El usuario escribe el nombre o parte del nombre y el sistema filtra los resultados.

## CU-04 Editar producto
**Actor:** Administrador/usuario de la tienda.

**Flujo:** El usuario selecciona Editar, modifica los datos y presiona Actualizar.

## CU-05 Eliminar producto
**Actor:** Administrador/usuario de la tienda.

**Flujo:** El usuario selecciona Eliminar y confirma la operación.
